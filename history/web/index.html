v2.11 배포 때 지도(sj-lab-mapservice)가 지워지는 원인 규명과 재발 방지 2026-09-23
  • 원인 — 지도는 허브 디렉터리의 하위 폴더(html/map)라, 허브 배포 잡이 상위 디렉터리를 비울 때 함께 삭제됨(v2.13에서 cleanRemote: true 로 확정). 지도 잡은 자기 폴더만 비우므로 범인이 아님
  • 증상이 숨던 이유 — nginx try_files $uri $uri/ /index.html 폴백 때문에 지도가 지워져도 /map/이 404가 아니라 허브 첫 화면을 200으로 돌려줌
  • docs/deploy-static-sites.md 신설 — 허브 잡 안전 패턴(rsync --delete --exclude 'map/'), 지도 잡 원자적 교체(새 폴더 → mv), 배포 후 확인, 복구, 근본 분리(별도 디렉터리 + nginx alias) 절차
  • scripts/check-prod-sites.ps1 신설 — 허브·지도 표식으로 판별해 지도 경로에서 허브가 나오면 실패 처리(현재 실행 결과 둘 다 정상)
  • 부가 발견 — 저장소 문서(*.md)가 /map/ 아래로 공개되고 있어 배포 시 제외하도록 정리. .git·에이전트 설정은 복사되지 않아 노출 없음
  • 운영 Server 헤더가 차트 이미지와 달라, 공개 트래픽은 노드의 nginx가 처리하는 것으로 보임 — nginx 설정 변경 시 nginx -T로 확인 필요
